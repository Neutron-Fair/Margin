## 本次内容

两个只在 Windows 上能遇到的交互问题。

### 修复：桌面端根本没有「更多」入口

「更多」那个面板（成本分档、参数自检、检查更新、恢复默认参数）之前**只在手机布局里显示**——桌面页头把它的按钮用 CSS 藏掉了，所以你在 Windows 上无论怎么找都找不到，检查更新自然也进不去。

- 现在桌面页头「设置」右边多了一个「更多」按钮，点开就是同一个面板
- 手机端不变，仍是原来的图标入口

### 修复：面板滚动会带着背后的页面一起动

打开设置之类的面板，滚轮滚到面板底部之后会继续把滚动传给主页面，表现为「我在滚设置，后面的算价页跟着滑」。

- 现在面板打开期间背后页面完全冻结：面板内部还能滚就正常滚，滚到顶或到底就停住，不会传给主页面
- 关闭面板后恢复原来的滚动位置，不会跳回顶部
- 键盘的 PageUp / PageDown / 空格 / 方向键同样被约束
