## 本次内容

### 「检查更新」不再要求填仓库地址

之前打开这个面板，先看到的是「仓库」两个输入框和「Token」——其实那两项都已有默认值，公开仓库也不需要 Token，摆在那里只会让人以为要自己配。

现在：

- **打开就自动检查**，不用先点一次；结果直接显示（已是最新 / 发现新版 + 更新说明 / 检查失败原因）
- **只剩一个按钮**，文案跟着状态走：检查中 →「检查中…」；已是最新 → 「重新检查」；发现新版 → 「下载并安装」（手机上为「打开下载页」）
- **仓库地址与 Token 收进「高级设置」**，默认折叠、看不见。默认值就是 `Neutron-Fair/Margin`，只有换发布源或仓库改私有时才需要动
- 兜底：如果某个 Release 里没有当前平台的安装包（比如用浏览器打开这个页面），按钮会变成「打开下载页」，跳到发布页手动下
