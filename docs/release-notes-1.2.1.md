## 本次内容

这一版**没有新功能**，主要是把对外发布的东西收拾干净，另外修掉了一处「装了新版却收不到更新」的问题。

### 变更：Android 改用调试证书签名

release 包不再使用项目自带的签名证书，改用 Android 默认的调试签名。

- 仓库与文档里不再包含任何签名证书、指纹或口令说明
- **影响**：1.2.0 已经改用调试签名，与本次同一把 → 装过 1.2.0 的可以直接覆盖；1.1.x 与 1.0.0 用的是旧证书，不同签名，**需要先卸载旧版再装**
- 以后如果要对外分发并支持覆盖升级，请自行配置 `signingConfig`，并保证每次构建都用同一份证书；否则签名一变，设备上就装不上去

### 变更：文档不再描述项目的演进来源

README 只描述当前形态与功能，不涉及项目是怎么一步步演进来的。技术细节（计价口径、构建步骤、测试验收）都保留。

### 修复：同版本重装后收不到更新提示

改版本号后，旧版本点「更多 → 检查更新」即可看到 1.2.1。

- 检查更新的判断是拿远端最新的 tag 和本地版本比较，只有**大于**本地版本时才提示
- 所以重新发布同一版本号只会换掉下载文件，客户端不会收到提示——这次把版本号提到 1.2.1 就是为了让升级链路真正跑通

### 沿用

- Windows 覆盖安装的修复（1.2.0 引入）继续有效
- 自动检查更新（桌面「下载并安装」/ 手机「打开下载页」）继续有效，更新源默认 `Neutron-Fair/Margin`；仓库是公开的，不需要填 Token
